WEBSITE ULANG TAHUN FITRIA
===========================

Isi folder:
- index.html     halaman website
- style.css      desain dan animasi
- script.js      interaksi tombol
- assets/        tempat foto dan musik

PERSONALISASI FOTO
1. Siapkan foto Fitria yang ingin dipakai.
2. Masukkan foto ke folder assets.
3. Ubah nama file foto menjadi: fitria.jpg
4. Pastikan file berada di: assets/fitria.jpg

MUSIK (OPSIONAL)
1. Pilih musik yang boleh kamu gunakan.
2. Masukkan file audio ke folder assets.
3. Ubah nama menjadi: music.mp3
4. Pengunjung harus menekan tombol musik karena browser biasanya melarang audio otomatis.

CARA MENCOBA DI LAPTOP
- Buka folder ini.
- Klik dua kali index.html untuk melihat website di browser.

CARA MEMBAGIKAN LINK GRATIS DENGAN GITHUB PAGES
1. Buat/login ke akun GitHub.
2. Buat repository baru, misalnya: birthday-fitria
3. Upload index.html, style.css, script.js, dan folder assets beserta isinya.
4. Buka Settings repository > Pages.
5. Pada Build and deployment, pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu beberapa menit. GitHub akan memberikan link website.
8. Buka link itu untuk mengetesnya, lalu kirim melalui WhatsApp.

CATATAN
- Pastikan foto Fitria memang pantas dan nyaman untuk dibagikan.
- Jangan unggah foto atau informasi pribadi yang tidak ingin dilihat orang lain.
- Desain memakai Google Fonts sebagai peningkatan tampilan; bila offline, font cadangan akan digunakan.
- Ganti teks surat di index.html bila ingin menyesuaikannya.
